# Calculadora com Interface

Uma aplicação simples de calculadora com interface gráfica desenvolvida em Python usando `tkinter`.

## ✨ Visão Geral

Esta calculadora permite realizar operações básicas com uma interface amigável:
- Adição
- Subtração
- Multiplicação
- Divisão
- Limpar entrada

O projeto é leve e ideal para quem está começando com Python e interfaces gráficas.

## 🧩 Estrutura do Projeto

```
Calculadora com interface/
├── calculadora.py
└── README.md
```

## 🚀 Como Executar

1. Certifique-se de ter Python instalado.
2. Abra um terminal na pasta do projeto.
3. Execute:

```bash
python calculadora.py
```

## 💡 Recursos

- Interface gráfica criada com `tkinter`
- Operações básicas de cálculo
- Tratamento simples de erros

## 🎯 Observações

- A entrada é avaliada com `eval`, portanto use apenas números e operadores básicos.
- Em caso de expressão inválida, a calculadora exibirá `Erro`.
